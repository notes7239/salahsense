アプリとその設定の使い方 · スマートフォンとウォッチ

重要： ラクアとサジダの自動検出にはウォッチが必要です（Apple WatchWear OS ウォッチ）。スマートフォン単体では手首の動きを測定できません。検出はあくまで補助であり、誤認識することがあります。ウォッチの位置、バンドの締め具合、個人差のある動きがその精度に影響します。記録はいつでも手動で修正できます。本アプリは宗教的な判断を下したり、礼拝の有効性を判定したりするものではありません。

よくある質問とお問い合わせ先はサポートページをご覧ください。太字はアプリ内のボタンやメニューの名称です。

1. はじめに

  • iPhoneAndroidスマートフォンアプリには礼拝時刻、キブラ、ズィクル、履歴、設定が表示されます。Apple WatchWear OS ウォッチアプリは礼拝中の動きを追跡し、アザーンのアラートとキャリブレーションを管理します。
  • まず、スマートフォンで設定タブ位置情報と設定ページを開き、位置情報、計算方法、アスルの計算、性別を設定してください（2と8を参照）。
  • 次にウォッチで一度キャリブレーションを行ってください。自動追跡はそれ以降でないと信頼できません。
  • ウォッチがなくても、礼拝時刻、キブラ、ズィクル、手動での礼拝済みにする記録、カダー、統計、ヒジュラ暦、ラマダーン時刻表、ウィジェットは利用できます。
  • 礼拝ガイドには、定時礼拝と忘却のサジダについて出典付きのオフラインで読める要約が収められています。礼拝の祈願文のページには、礼拝中に唱える祈願文がアラビア語本文、読み方、意味とともに収められています。スマートフォンのズィクル画面では、タスビーフモードが礼拝後の33回ずつの三つの数を順に数えます。
  • ズィクルタブの日々の祈願文には、イブン・アラビーの祈願書『アル＝アウラード・アル＝ウスブーイーヤ』（週のウィルド）の序文と十四のウィルドが並びます。週の毎夜と毎日に一つずつです。いまのカードには、いま読むウィルドが表示されます。夕方の礼拝の時刻から朝までは翌日の夜のウィルド、朝から夕方まではその日のウィルドです。祈願文は一続きの本文として開き、上のアラビア語・読み方・意味ボタンで表示する部分を選べます。祈りの中のクルアーンの引用は訳さず、意味は末尾の脚注に示します。リストからウィルドを外したり、祈願文を追加で戻したり、タイトル・アラビア語・読み方・意味を入れてご自身の祈願文を追加したりできます。ご自身の祈願文はこのスマートフォンにのみ保存されます。右上の Aa ボタンで読み方の表記方式（DIN 31635 または İSAM）、アラビア語の文字サイズ、ページの色調を選べます。これらは暗記と共通です。アッラーの美名、クルアーンのアーヤ、サラワートはそれぞれ別の色で表示されます。意味の本文では、アッラーの美名は訳さず、アラビア語の名前を読み方で表記します。アーヤまたはその番号をタップすると、スーラとアーヤの番号、ムスハフの本文、訳が表示されます。アッラーの美名をタップすると、その意味が表示されます。色は Aa ボタンの色で変更したり、なしにしたりできます。
  • ズィクルタブでは、タスビーフと自由カウントのカードの下に自分のズィクルを保存できます。新しいズィクルで読み方を入力し、必要ならアラビア語と意味も入力します。カウントは33・99・100・カスタム目標・自由から選び、色も選びます。目標に達するたびに強く振動します。ウォッチにも表示をオンにしたズィクルはウォッチのズィクル画面で選べます。カウンターはデバイスごとに別です。リストには既定のズィクルが入っています。4つのドゥアーとクルアーンの33の節です。既定のズィクルはスマートフォンにのみ表示されます。どれでも「ウォッチにも表示」をオンにできます。既定のズィクルは編集や削除ができます。
  • 履歴を共有するには、iPhoneの設定 → ペアリングされたデバイスで礼拝の履歴をペアリングしたiPhone/Apple Watchと共有を、ウォッチのデバイスのペアリングで履歴を同期をオンにしてください。既定ではオフです。今すぐ同期すると古い記録も送信されます。
  • スマートフォンとウォッチの同期には両方の端末にアプリが必要です。接続がない場合、記録はその端末に残ります。必要な場合は位置情報と設定 → 同期を再試行を使ってください。
  • 初めて起動すると、アプリは端末の言語で開きます。その言語に対応していない場合は英語で開きます。言語は、スマートフォンでは設定 → 言語、ウォッチでは言語で変更します。選択はそれぞれの端末ごとに保存されます。
  • 時刻は端末の12時間／24時間表示の設定に従います。日付はどの言語でも西暦とアラビア数字（1、2、3）で表示されます。ヒジュラ暦の日付はヒジュラ暦の日付調整の設定に従って別に表示されます（9を参照）。
  • 設定 → 外観：自動は端末のライト／ダーク設定に従います。ライトまたはダークを選ぶと、アプリとヘルプがそれに従います（暗記でページの色調を自動にした場合も同様）。ウォッチは常にダークで、ホーム画面のウィジェットは端末の設定に従います。選択はこの端末に保存されます。

2. 位置情報と礼拝時刻

  • iPhone：設定 → 位置情報とタイムゾーン。自分の位置情報を使うをタップして位置情報の利用を許可するか、都市、緯度、経度、IANAタイムゾーン（例：Asia/Tokyo）を入力し、都市／位置情報を保存をタップしてください。
  • 位置情報と設定：自分の位置情報を取得をタップするか、位置情報の名前、緯度、経度、タイムゾーンを入力して保存をタップしてください。
  • 位置情報の利用許可は任意です。都市と座標は手動でも入力できます。旅行の際は位置情報とタイムゾーンを更新してください。
  • 計算方法（12種類）：トルコ（ディヤーネト）、世界ムスリム連盟、エジプト（測量総局）、カラチ（イスラム科学大学）、ウンム・アルクラー（マッカ）、ドバイ、新月観測委員会、北米（ISNA）、クウェート、カタール、シンガポール、テヘラン。お住まいの地域の時刻表に最も近いものを選んでください。
  • アスルの計算：標準は影の長さが物の長さと同じになった時点（アスル・アウワル）、ハナフィー派は2倍になった時点（アスル・サーニー）を基準とします。トルコの時刻表は標準を使用します。
  • 法学派：スンニ派（スンナ＋ウィトルを含む）またはシャーフィイー派（ファルド）。これは追跡するラクアの構成のみを決め、礼拝時刻には影響しません。ウォッチでは法学派 / ラクアにあります。
  • 変更後、礼拝時刻は自動的に更新されます。必要であれば礼拝時刻を更新をタップしてください。ウォッチでは計算方法とアスルの計算は計算方法にあります。
  • 礼拝時刻は端末上で計算されます。本アプリは公式の時刻表ではなく、お住まいの地域の時刻表と数分の差が生じることがあります。

3. 通知とアラーム

礼拝時刻の通知

  • 礼拝時刻になったら通知をオンにすると、各礼拝時刻に通知が届きます。ステッパーで時間を設定してください：礼拝時刻に、または最大60分前（…分前）・後（…分後）。ウォッチにも同じ設定がアザーン・アラートにあります。
  • ウォッチがこれらの通知を処理している場合、iPhoneは独自に通知を設定しません。iPhoneがロックされていても通知はウォッチに届きます。
  • 位置情報と設定：リマインダーをオンにし、礼拝時刻にまたは…分前を選択してください。通知が遅れる場合はスケジュール権限を許可してください。

礼拝時刻終了前のアラーム

  • 礼拝時刻終了前のアラーム：オフ、または礼拝時刻終了の何分前かを設定します。その礼拝が礼拝済みとして記録されていない場合、サイレントモードでも鳴ります。
  • アラームを鳴らす礼拝：アラームがオンのとき、各礼拝ごとに個別のスイッチがあり、選択した礼拝（例：ファジュルのみ）でのみ鳴ります。既定ではすべてオンです。
  • ウォッチが検出した記録がまだスマートフォンに届いていない場合、鳴ることがあります。
  • アラームをテスト：同じアラームを1分後に設定します。スマートフォンをロックしてお待ちください。朝を待たずに、スマートフォンでアラームが鳴るかを確認できます。テスト用アラームは最長1分間鳴ります。
  • 実際のアラームにはiOS 26が必要です。それ以外の場合、またはアラームの権限がない場合は、代わりに通知が送信されます。
  • 終了の45分前と30分前に、ウォッチはアザーンのハイヤ部分を振動とともに再生します（ハイヤ・アラッサラー、ハイヤ・アラルファラーフ）。眠っている場合はもう一度より強く鳴ります。時間内に座ったまま、または横になったままでいるようであれば、手が空いているようですという通知が1回届きます（忌避される時間には届きません）。

タハッジュドとファジュルのアラート（ウォッチ）

  • ウォッチの設定 → アザーン・アラートアザーン・アラートでは、タハッジュド・アラートは夜の最後の三分の一に、ファジュルのアザーン・アラートはイムサークに合わせて設定されます。
  • アラート時刻：礼拝時刻に、または5〜60分前。スヌーズ：1〜15分。
  • 動くと一時的にアラームが消音され、礼拝済みにするをタップすると停止します。必要な動きの量は消音ジェスチャーで設定します：動きを抑えて（高感度）、中、動きが多い（難しい）。
  • 直近のアラームでは選択したアザーンの音が再生され、それ以外のアラートは通知音が使われます。ウォッチアプリを開くと直近のアラームが更新されます。
  • 音と振動は端末の通知チャンネル（アラート音とバイブレーション）から再生されます。アプリに内蔵のアザーン音源はありません。

アザーンの音（Apple Watch）

  • アザーンの音（またはアザーン・アラート → アザーンの音を選択）：CAF、AIFFまたはWAVファイルのhttpsアドレスを入力し、ダウンロードをタップしてください。通知では最大30秒まで再生され、それより長いファイルはアプリ内でのみ再生されます。
  • インストールした音源を選択し、再生、停止、削除で管理します。何も選択されていない場合は、内蔵のアラーム音が再生されます。
  • ハイヤ部分（リピート＋バイブレーション）：「ハイヤ・アラッサラー、ハイヤ・アラルファラーフ」の部分を開始と終了の秒数で指定し、繰り返し回数を設定してセグメントを再生で確認してください。
  • ファイルはそのアドレスから直接ダウンロードされます。そのサーバーは当社のものではありません。

通知の権限、サイレントモード、フォーカス、バッテリー節約、音量のいずれもアラートに影響することがあります。

4. ウォッチでのキャリブレーション

キャリブレーションでは、ご自身のタクビール、キヤーム（立礼）、ルクー、サジダ、座位の姿勢をウォッチに学習させます。キャリブレーションはウォッチでのみ行います。

  1. いつも着けている手首に、ウォッチをしっかりと装着してください（右手首でも左手首でも構いません）。
  2. キャリブレーション → 個人キャリブレーション（ウィザード） → 音声キャリブレーションを開始キャリブレーション → 音声キャリブレーションを開始。
  3. 音声の指示に従ってください：タクビール（両手を上げる）、キヤーム、ルクー、立ち上がり、サジダ、2回のサジダの間の座位、2回目のサジダ、最後の座位、右へのサラーム、左へのサラーム。各指示の後に姿勢をとる時間があり、続いて短い計測が行われます。無理のない範囲で動かずにお待ちください。
  4. ドゥアーの終了ジェスチャーを学習（任意）をオンにすると、サラームの後に両手で顔を拭う動作も計測されます。不要な場合はドゥアーの動作をスキップをタップしてください。
  5. 停止で一時停止し、中断した手順から再開で続行します。
  6. 最後にキャリブレーション完了と、キヤームを基準にした手首の高さが表示されます。完了、礼拝に戻るをタップしてください。
  • サラームは音声でのみ案内され、頭の動きは計測されません。
  • キャリブレーションが正常に完了すると、継続検出が自動的にオンになります。
  • 姿勢が似すぎている、またはタクビールが認識されなかった場合は、同じ手首で最初からやり直し、タクビールの手順では両手を上げたままお待ちください。

2番目の位置

  • 礼拝中にウォッチが手首をずり落ちる場合は、その位置も学習させてください。通常のキャリブレーションの後に2番目の位置をキャリブレーションをタップし、ウォッチを手の方向に1〜2cmずらして、同じ手順（顔を拭う動作を含む）を繰り返します。
  • 検出はより適合する位置を使用します。新しく通常のキャリブレーションを行っても2番目の位置は保持されます。バンドの締め具合が変わった場合は2番目の位置を再キャリブレーション、または2番目の位置を削除を使ってください。

いつ再キャリブレーションするか

  • ウォッチの位置、バンドの締め具合、または手首が変わったとき、あるいは検出がよく間違えるときに行ってください。ウォッチの位置を確認してくださいという通知も、ウォッチが緩んでいることを示します。
  • 本アプリは礼拝からも手首の高さを学習します。大きな変化があった後は学習した高さをリセットを使用してください。キャリブレーションを削除はキャリブレーション全体を削除します。
  • 音声練習では、音声案内に合わせて練習できます。記録は作成されません。

5. 礼拝中の自動追跡

  • 礼拝時刻内にウォッチアプリを開き、開始のタクビールから始めてください。各セクション（スンナ、ファルド、ウィトル）はそれぞれ独自のタクビールから始まります。両手を上げる動作が検出されると、タクビールの姿勢を検出しました。キヤーム（立礼）に移ってください。と表示されます。
  • 順序は開始のタクビールに従います：ファジュル 2+2 · ズフル 4+4+2 · アスル 4+4 · マグリブ 3+2 · イシャー 4+4+2+3 ウィトル。マグリブはファルドから始まります。シャーフィイー派（ファルド）の場合は、ファルドのみが追跡されます。
  • 画面には現在のセクション、次のタクビール、検出されたラクア数が表示されます。
  • 最初のスンナを行わずに直接ファルドから始める場合は、最初のスンナをスキップファルドから開始をタップしてください。
  • 忘却のサジダは礼拝の最後、最後の座位で行います。検出された場合、記録に忘却のサジダを実施と表示されます。
  • 礼拝のセクションが開始のタクビールで始まると、サジダ中に画面に誤って触れないよう、ウォッチは防水ロックをオンにします。解除するにはDigital Crownを回してください。セクションの途中でロックを解除すると、ウォッチが防水ロックが解除されましたと尋ねます。このセクションをやり直しますは新しい開始のタクビールから数え直し、続けるはセクションを続けます。不要な場合は検出設定 → 防水ロックでオフにできます。検出には影響しません。
  • このセクションをやり直しますは現在のセクションを初めからやり直します。保存に失敗した場合は保存を再試行をタップしてください。
  • セクションを最初からやり直すには、ウォッチでこのセクションをやり直しますをタップします。
  • キャリブレーションが行われていない場合は、個人キャリブレーション（ウィザード）ボタンが表示されます。

回数の誤りや礼拝の検出漏れ

  • ラクアが多すぎる、または少なすぎると検出された場合、ウォッチが警告します（ラクア数を確認してください）。ご自身でラクア数を確認してください。
  • 間違いに気づいてセクションを最初からやり直す場合は、両手をタクビールの位置で約5秒保ち、キヤーム（立礼）に下ろしてください。ウォッチが振動して長いタクビール：このセクションを最初から数え直します。と表示し、数え直しが始まります。画面に触れる必要はありません。通常のタクビール、クヌート、10秒を超えて手を上げたままにすることではセクションは変わりません。最後まで礼拝したセクションの後の長いタクビールは次のセクションを開始します。
  • 足りないラクア数でドゥアーにより終えたセクションをやり直すとき、開始のタクビールが認識されなくても、最初のラクアが終わるとやり直しとして数えます。
  • カダーセッション中にあるセクションでラクア数やサジダ数のアラートが出ると、ウォッチに表示されます。もう一度礼拝するは同じカダーを新しい開始のタクビールから待ち直します。このまま続けるはそのセクションを礼拝済みとして数え、アラートを記録に残して次のカダーに進みます。
  • セクションの開始のタクビールが礼拝が忌避される時間（日の出後45分、ズフル前10分、マグリブ前45分）に検出されると、ウォッチが振動し礼拝が忌避される時間には礼拝を行いません。と表示します。記録は変わりません。ハナフィー派の実践（スンナとウィトルを含む）では、その日のアスルのファルドはマグリブ前の忌避される時間でも警告されません。
  • 礼拝を手動で記録するには、ウォッチでファルドを礼拝済みにする礼拝済みにする、スマートフォンで礼拝済みにするをタップしてください。スマートフォンの礼拝済みにするは先に確認します。ダイアログの礼拝済みにするで記録し、キャンセルでは何も記録しません。手動で記録したファルドは、ウォッチの礼拝の手順に記録元と時刻とともに表示されます（例：スマートフォンで「礼拝済みにする」 · 21:09）。ほかの端末からの記録はオレンジ色です。
  • 時間内に礼拝したのに検出が見逃した場合は、礼拝時刻が終了した後にスマートフォンで履歴を開き、時間内に礼拝済みにするをタップして礼拝した時刻を設定し、礼拝済みとして保存をタップしてください。時刻はその礼拝時刻の範囲内である必要があり、この操作は取り消せません。
  • 履歴で誤った記録を記録を元に戻すで取り消し、改めて礼拝済みにするをタップできます。

継続検出とバッテリー
